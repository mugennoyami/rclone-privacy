Privacy Policy

Last updated: 4 November 2026

"rclone" is a private application used only by its owner, Simon Heinen, with his own Google account.

Data accessed

The app requests access to Google Drive and Google Docs (scopes auth/drive and auth/docs) in the owner's own account, only to read, create and update the owner's own files (personal notes).

Use and storage

Data is used only to sync these files between the owner's devices. Access tokens are stored on the owner's own devices. No data is collected on a server of the app, sold, shared with third parties or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
